# Sejro Labs - Plateforme de scoring de rachat

## Objectif

Construire une plateforme qui estime, pour chaque client éligible,
la probabilité de réaliser un nouvel achat dans les 90 jours.
Le score aidera une équipe CRM à constituer des segments selon
leur probabilité de rachat.

## Données

Le projet s’appuiera sur les données de commandes du jeu de données
Olist Brazilian E-Commerce.

## Livrable

Une API FastAPI exposera les probabilités de rachat et les principaux
facteurs qui contribuent à chaque prédiction.
